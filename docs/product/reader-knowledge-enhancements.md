## 安全与设计边界

- 原始电子书不可变；索引、裁边和笔记不写回文件。没有复制或上传用户书籍作为测试。
- 全文索引共享书籍正文；查询、计数和出处打开均应用当前书库权限。笔记与智能规则是账号私有数据。
- 新索引只使用 EPUB 正文和已有 PDF 提取文本，不自动执行 OCR，不启用 AI，不发起正文外传。现有 AI 分类配置不因此变为正文问答配置。
- 后台索引有持久队列、租约和重试；管理员可在正文检索页点击“补建／更新索引”，在既有运维页面查看 `text-index` 任务。新增 EPUB 导入与 PDF 文本提取后会入队；Calibre 只读引用变更可显式补建。
- 一次完整索引事务替换书籍片段；失败保留旧索引，旧源哈希／提取方法变更后旧索引不会继续参与查询。删除书籍级联删除其索引。
- 搜索为大小写不敏感的字面子串，不是语义检索、分词排序或模糊问答。关键词 2–200 字，每页 24 条，最多 50 页，查询 5 秒超时。2 字短词可能不能充分利用 trigram 索引，NAS 性能需实测。
- EPUB 出处是章节而非精确段落；PDF 有真实页分隔／OCR 页标记才返回页码。不知道页码时明确标注，并按原阅读进度打开书籍。OCR 可能只覆盖部分页，不声称全文覆盖。
- 索引输入最多 16 MiB，EPUB 单章节 4 MiB／20000 个 ZIP 条目、章节路径 2048 字节，每本 10000 片段；PDF 页分隔／OCR 标记最多 10000 页。超限报任务失败，不静默截断。每片段最多 1600 字、200 字重叠，不索引 script/style。
- 智能书架所有规则 AND 匹配：格式、当前账号阅读状态、收藏、精确题材分类。按书名动态排序；不能手动增删或排序，不隐式转换已有手动书架。
- 裁边四边各 0–20%，按账号／书籍保存在当前设备；原页坐标仍用于批注和进度。文字阅读只包装当前页提取文本，不保证多栏、图片、表格顺序，也不造出 OCR 内容。

## 离线批注与草稿

- 手动保存书籍到设备时同时缓存批注；已打开的书籍也会缓存其在线批注。离线修改存到当前账号的 localStorage 日志（2 Mi 字符／2000 个待同步操作上限），恢复联网后按顺序回放。
- UUID 操作回执和批注事务同时提交；重试不重复创建。更新／删除携带服务器时间戳，其他设备改动产生冲突；本地草稿保留，可导出或显式放弃后读取服务器版本。
- 回放请求含预期账号 ID，防止另一标签页切换 Cookie 后误把旧账号笔记写入新账号。退出登录清除设备笔记，返回中的旧请求不能恢复已清除缓存。
- 删除批注后回执只留删除标记，不保留已删正文；删除书籍／账号级联删除关联回执。为长期离线重试安全，不对幂等回执设置短期 TTL；其持续增长仍需后续运维策略。
- 同标签页串行回放；浏览器提供 Web Locks 时跨标签页串行。在不提供该能力的普通 HTTP 环境，不承诺多标签同时离线编辑不会竞争；PWA／完整离线阅读仍要求 HTTPS（localhost 除外）。
- 设备导出含私有摘录及草稿，应自行妥善保管。浏览器清理站点数据会丢失未同步草稿；不能把浏览器缓存当成备份。
- JSON 导入最多 200 条／2 MiB，支持本应用跨书及单本导出；校验书籍 ID、书名和格式，不猜测跨服务器 ID 映射。逐条导入不是原子整批，失败显示已处理数，可安全重试原文件。
- 草稿保护覆盖阅读器笔记／高亮、笔记中心、书架编辑／新建、离开阅读器和退出登录。未宣称所有后台表单已覆盖；浏览器原生离页弹窗仍取决于浏览器策略。

## 下一批验收门槛

1. TTS 先确定本地引擎及模型资源，再加入可重试／取消的生成任务和账号权限化音频缓存；云端需管理员明确启用并在发出正文前展示用户确认。
2. AI 先实现本地检索证据、管理员允许范围和提供者配置，再生成可校验的引用；无证据时拒答，不允许模型绕过权限。
3. 第三方笔记同步需用户确定 Obsidian／WebDAV／其他目标与单向或双向策略，之后再设计凭据、冲突和删除语义。未选定前保持本地导入／导出。
4. EPUB 跨框架选区与真实手机原生长按行为独立验收，不用 Pixel 视口测试代替 iPhone／Android 真机。
