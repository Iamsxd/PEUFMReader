# 个人阅读工作台增强

日期：2026-10-03。

## 版本与数据边界

- 分支：`codex/reading-library-enhancements`，基于 `799620f`（最新阅读工作台 UI）。
- 保留文学杂志／深夜书房双主题和响应式导航；本次不推送、合并、触发远程发布或替换现有运行服务。
- 新增迁移 `030_personal_reading_workspace.sql`：个人书架、书籍关联／顺序，以及跨书笔记排序索引。不复制、移动或修改书籍源文件，不迁移生产数据库。
- 书架按账号隔离；查询笔记、书架内容、计数与所属状态时均使用当前用户的可访问书籍集合。失去阅读权限后记录隐藏而非删除。
- 删除书架只级联删除该书架关联；移除书架中的书籍不影响书籍、收藏、进度或批注。添加／调整顺序锁定书架行，在多设备并发下保持顺序确定且重复添加幂等。
- 生产升级先使用现有 `scripts/backup.sh` 和 `scripts/verify-backup.sh`。只切换 Git 分支不会撤销数据库迁移；旧应用可忽略新增表，不要手工删除数据库目录。

## 功能范围

- 桌面侧栏、手机更多菜单新增“我的书架”“我的笔记”。
- 书架创建、名称／说明编辑、目录搜索添加、从详情页加入、提前／延后排序、移除与安全删除；书籍列表服务端分页。
- 跨书笔记中心按书名、标签位置、摘录和批注搜索，类型／颜色筛选，更新时间倒序分页；复用原有批注编辑／删除接口。
- 回到原文使用记录中的 PDF 页码或 EPUB CFI／章节位置作为初始视口，不额外请求覆盖进度；进入阅读器后仍执行正常的阅读位置保存策略。
- 详情页提供单本笔记入口与书架选择，管理员操作单独展开；阅读器侧栏增加本书批注搜索／类型／颜色筛选。
- 设备接入说明按 OPDS／KOReader／Kobo 切换，支持复制地址，剪贴板不可用时提示手动复制；不宣称新增原生客户端或完整 Kobo 云服务。

本阶段没有新增外部服务、翻译／词典、分屏阅读、跨书全文检索、漫画、有声书管理、阅读目标或批注外部同步。跨书导出暂未实现，已有单本 Markdown／JSON 导出保持不变。离线时仍进入离线书架，新工作台功能需要联网。

## 验证方法

- 宿主机没有 Go 工具链，使用项目匹配的 `golang:1.26.6-bookworm` 容器，在挂载的 `server/` 下执行 Go 测试与 vet。
- 集成测试使用单独的临时 PostgreSQL 18 容器和隔离 schema；不连接现有应用数据库，不读取真实电子书。
- 新增集成测试覆盖账号隔离、权限撤销、查询校验、字面百分号搜索、分页、书架同名冲突、CSRF、重复添加、并发追加、调整顺序与删除不影响原书／批注。
- Playwright 使用合成账号、内存 API 与原创 PDF／EPUB，覆盖两套主题、桌面／Pixel 7 模拟视口、320px、搜索编辑删除、书架维护、设备说明、错误提示、导航和 PDF／EPUB 原文定位。
- 额外的 `personal-workspace-live.spec.ts` 必须显式启用 `E2E_WORKSPACE_SCRATCH=1`，并限制在 `http://127.0.0.1:5189`；在独立临时实例上传原创合成 PDF，经真实接口创建书架／批注、刷新验证持久化、回到原页，确认删除书架后书籍与批注仍存在。不在现有 NAS 服务上运行此写入测试。
- 阅读器场景按 PDF／EPUB 独立进程执行，使用软件渲染，避免此前本机跨套件复用 Chromium 的原生崩溃。

## 验证结果

- 前端单元测试：67 项通过；`pnpm build` 通过，保留既有 PDF 分包大于 500 kB 的提示。
- `go test ./...`、`go vet ./...` 和设置独立 `TEST_DATABASE_URL` 后的 `go test -tags integration ./...` 通过，包含数据库迁移重复执行与新的权限／并发／排序验证。
- Docker 运行镜像构建成功，没有推送到镜像仓库。
- 生产构建浏览器回归：个人工作台合成场景 16 项、真实接口往返 2 项、双主题 24 项、原布局交互 10 项、应用外壳 3 项通过，共 55 项通过；外壳中的桌面“仅移动视口”场景按设计跳过 1 项。不把跳过项算作通过。
- 未执行原推荐反馈写入场景，本次不修改推荐逻辑。所有本轮写入均发生在独立临时测试实例，不读取真实书库。
- 检查原文跳转后的断网／重连：初始批注只用于第一次定位，不会在网络恢复时再次覆盖正在阅读的位置。

初次验证捕获并修复了笔记搜索转义、顺序交换参数类型和测试夹具完整类型问题；浏览器复测同步新导航顺序与展开管理区，并修复了旧首页加载测试未等待 hash 路由挂载的竞态。手机阅读工具按中心触控唤醒，不依赖桌面显示按钮。

最终镜像的临时实例首次访问曾早于服务就绪而返回空响应；确认 `/healthz` 正常后重新运行对应阅读器测试，不把该失败批次计为通过。

真实 iPhone／Android、真实 NAS 性能、生产升级／恢复演练仍不属于本次本机验收范围。临时容器与合成测试数据在验证结束后清理，保留本机截图；原 8080 服务与运行数据库保持不变。

## 常规复现

```sh
cd server
go test ./...
go vet ./...
# TEST_DATABASE_URL 必须指向专用测试数据库；测试会创建和清理隔离 schema。
go test -tags integration ./...
cd ../web
pnpm test
pnpm build
# 启动生产预览后，设置 E2E_BASE_URL，并按套件运行。
export E2E_DISABLE_GPU=1
export E2E_DISABLE_VIDEO=1
pnpm test:e2e e2e/personal-workspace.spec.ts --grep-invert 'marked PDF|marked EPUB' --workers=1 --reporter=list
pnpm test:e2e e2e/personal-workspace.spec.ts --grep 'marked PDF' --workers=1 --reporter=list
pnpm test:e2e e2e/personal-workspace.spec.ts --grep 'marked EPUB' --workers=1 --reporter=list
```
