# 双主题界面验证

日期：2026-09-19

## 范围与边界

- 文学杂志（默认）：纸白、钴蓝、衬线标题、编辑式首页。
- 深夜书房：炭黑、青柠、书封层叠与柔和光影。
- 登录页和导航栏提供原生主题选择器；选择保存在 `peufmreader.app-theme`，同源标签页通过 storage 事件同步。存储失败时本页仍可切换，无服务端配置或数据库迁移。
- 首页分区、搜索、导航、权限、书目操作及上传队列保持原逻辑。主题切换不重挂载页面，不重新请求首页概况。
- 主题颜色变量限定在书库与登录外壳；PDF/EPUB 阅读器沿用原有颜色回退值，正文主题和阅读进度独立。
- 封面保留完整比例，缺失封面使用本地文字排版；不访问外部图片服务。所有浏览器测试书目与 PDF 均为合成数据，不写入真实书库。

## 验证结果

- `cd web && pnpm test`：12 个文件、66 项测试通过。
- `cd web && pnpm build`：通过，PDF、EPUB、管理工作区继续独立拆包；原有 PDF 分包大于 500 kB 的提示仍存在。
- 生产构建预览上的 `themes.spec.ts`、`site-shell.spec.ts`：19 项通过，1 项按设计跳过（桌面项目不执行移动专属断言）。
- 浏览器矩阵：桌面 Chrome、Pixel 7 模拟视口，附加 320px 窄屏。
- 覆盖两套主题切换与刷新恢复、跨标签页同步、搜索值保留、书库导航、详情、PDF 渲染和主题隔离、统计热力图五档颜色、管理导入页、存储拒绝、空书库、接口报错、长书名及封面 404 回退。
- 人工查看两套主题的首页、目录、详情、统计与导入页截图；修正窄屏层叠书封越界。测试产物未纳入版本控制。
