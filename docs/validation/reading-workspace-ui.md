# 阅读工作台 UI 第一版

日期：2026-10-03。

## 版本边界

- 开发分支：`codex/reading-workspace-ui`。
- 基线：`c315060`（双主题版本）。原 `master` 不合并、不覆盖；本次只创建本地功能提交，不推送或触发镜像发布。
- 无后端、数据库迁移、权限、书籍文件或缓存格式变更。返回原 `master` 即可恢复旧界面，不需要恢复数据库。
- 使用自行编写的 React/CSS/SVG；只参考 BookOrbit 的书库组织、Readest 的阅读布局和 Linear 的控件密度，没有复制第三方代码、品牌或截图作为应用资产。

## 改动范围

- 桌面固定侧栏、当前页面面包屑、主题与账号工具区。导航加图标和当前页面语义，支持键盘跳到主要内容。
- 手机固定五项底部导航：首页、全部书籍、推荐、收藏、更多。分类和阅读统计进入更多菜单；离线、设备和管理员入口仍保留。
- 紧凑的欢迎／搜索区、横向继续阅读卡、阅读概况和优先展示的推荐书架；最近阅读、分类、热门与最近加入均保留。
- 书库封面网格、搜索／筛选、详情及后台工作区的间距、边框、圆角和字体调整。原有服务端分页、筛选、按钮操作与后台分包不变。
- 阅读器仅调整控制栏与侧栏外观。原来的显隐、翻页、正文主题、字号、笔记和进度逻辑不改；应用双主题仍不会传入正文。
- 保留“文学杂志”和“深夜书房”主题、持久化及跨标签页同步；安装提示在手机底部导航之上，保留安全区域。

## 验证

使用现代 Node.js 与 Playwright 匹配版本的 Chromium headless shell。测试与截图产物留在被忽略的 `web/test-results/`，不提交。

- `cd web && pnpm test`：66 项通过。
- `cd web && pnpm build`：通过，保留既有 PDF 分包体积提示；阅读器与后台继续按需拆包。
- `themes.spec.ts`：桌面／Pixel 7 模拟视口，覆盖双主题、持久化、跨标签页同步、搜索／详情／PDF、后台／统计、空书库／接口错误／长标题／封面失败、320/390/720/721/820/1024/1440px 断点、底部菜单与键盘跳转。
- 新增原创的两章合成 EPUB，只在内存中通过拦截接口供给浏览器；验证字号、独立阅读主题和目录跳转，不读取、上传或写入真实书籍。
- 生产预览补充回归：导航、首页渐进加载、四个后台工作区、3336 条合成待整理队列、PDF 工具／朗读、PWA 元数据和移动页面宽度。桌面的“仅移动视口”场景按原设计跳过。
- 最后调整推荐／最近阅读的展示顺序后，重新执行前端测试、构建和双主题搜索／导航／详情／PDF 回归。

最终生产预览按套件分开执行：主题／阅读器 24 项通过、布局交互 10 项通过、应用外壳 3 项通过／1 项按设计跳过，共 37 项通过。三轮命令均正常结束。推荐反馈测试会写入真实测试账号的偏好，本次未运行该项；没有改动推荐反馈代码。

本机环境注意：系统 Chrome 的长批次曾在退出时超时；匹配版本的 Chromium 在 PDF／朗读场景后复用到其他套件时仍出现原生 `SIGSEGV`。设置仅测试生效的 `E2E_DISABLE_GPU=1` 并按套件分开启动，最终各套件均通过。此记录不把这些失败批次算作通过，也没有为此改动应用的阅读器逻辑。

移动端为自动化模拟与断点检查，尚未在真实 iPhone／Android 设备上验收。没有生产部署，也没有进行数据库／书库迁移。

## 复现命令

先启动开发服务器或生产预览服务器，并将 `E2E_BASE_URL` 设置为对应地址。本次使用开发端口 5186、生产预览端口 5187，避免占用其他项目的 5173。

```sh
cd web
pnpm test
pnpm build
pnpm exec playwright install chromium
export E2E_BASE_URL=http://127.0.0.1:5187
export E2E_BROWSER_CHANNEL=
export E2E_DISABLE_VIDEO=1
export E2E_DISABLE_GPU=1
pnpm test:e2e e2e/themes.spec.ts --reporter=list --workers=1 --global-timeout=180000
pnpm test:e2e e2e/layout-and-interactions.spec.ts --grep-invert 'recommendation feedback' \
  --reporter=list --workers=1 --global-timeout=180000
pnpm test:e2e e2e/site-shell.spec.ts --reporter=list --workers=1 --global-timeout=180000
```

生产预览回归使用已有测试账号配置；不要在聊天或版本库中保存账号密码。主题／EPUB 套件使用合成身份与拦截 API，不依赖真实书库内容。
