# DeepSeek AI 批量分类验证

## 范围

本功能为管理员提供“未归类书籍”的 AI 批量分类建议。它复用现有固定题材与待整理队列：AI 的输出只能落为 `suggested` 状态，不能自动覆盖人工或规则已确认的分类。

V1 支持 `ollama`、通用 `openai-compatible` 和 `deepseek` 三种提供者；`deepseek` 留空服务地址时使用官方 `https://api.deepseek.com`，并以 JSON 输出模式请求分类结果。

## 数据与隐私边界

- 仅会发送书名、作者、出版年份、语言、摘要、主题和系统中启用的分类选项。
- 不发送电子书正文、原始文件、PDF 文字内容、阅读进度、笔记、高亮、用户名或访问权限。
- 单次任务只处理尚无已确认分类的版本，最多 5000 本；每次请求间隔约 200 毫秒，避免占满 NAS 或云端接口。
- 每本书的服务调用失败不会中断其余书籍；任务结果记录成功、跳过和失败数。全部失败时由后台任务重试机制处理。

## 管理员验收步骤

1. 在部署目录的 `.env` 设置以下值，并保管好 API Key：

   ```dotenv
   AI_PROVIDER=deepseek
   AI_MODEL=deepseek-v4-flash
   AI_API_KEY=你的_DeepSeek_API_Key
   ```

2. 运行 `docker compose up -d --build`，不要提交 `.env`。
3. 登录管理员账号，进入“管理后台 → 书目与分类”。确认页面显示“已配置”、未归类数量和可用分类数量。
4. 点击“测试连接”。成功提示不发送任何书籍信息；失败时检查 API Key、模型名、网络和容器日志。
5. 先点击“先分类 50 本”，确认隐私提示。到“管理后台 → 任务与运维”查看“AI 批量分类”的进度与失败信息。
6. 完成后到“待整理”筛选“分类建议待确认”，抽查分类理由并逐本确认或拒绝。确认后才会进入正式分类。
7. 小批量结果满意后，再选择“分类全部”。若未归类书超过 5000 本，页面会明确显示本次只处理前 5000 本。
